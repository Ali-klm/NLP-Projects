# Natural Language Processing Projects

A collection of NLP experiments covering text classification, sentiment analysis, clustering, and word embeddings. The repository includes projects with Persian text as well as general text-processing exercises.

## Projects

- **Persian Text Clustering and Sentiment Analysis** — clustering and sentiment analysis experiments on Persian text.
- **Sentiment Analysis with CNN and LSTM** — neural text classification with convolutional and recurrent models.
- **Text Classification with Different Neural Network Architectures** — comparison of neural approaches for text classification.
- **Word2Vec Skip-gram with Negative Sampling** — word-embedding implementation and experiments.
- **Word Embeddings for Sentiment Analysis** — applying pretrained or learned embeddings to sentiment tasks.
- **Hyperparameter Impact** — experiments exploring how parameter choices affect model behavior.

## Running the projects

Projects are organized in separate folders. Check the notebook or project files for the dataset source, package requirements, and run instructions. Data and dependencies may differ by project, and datasets may need to be downloaded separately.
